# Linan - Hex to Smali Color Converter

Convert hex colors (or pick one on a color wheel) into Smali color code.

**Features:** hex input + color wheel with brightness/opacity, instant Smali value
and `const` line, extra formats (signed, decimal, XML, Java), tints & shades,
Smali Color View (paste Smali code, see the color), history, copy/share.

## Build with GitHub
1. Create a repo and push these files to `main`.
2. Open the **Actions** tab, run **Build Linan APK** (runs automatically on push).
3. Download **Linan-debug-apk** from the run's Artifacts.

Java only, no external libraries, minSdk 21.
